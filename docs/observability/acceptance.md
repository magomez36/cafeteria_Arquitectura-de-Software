No se declara la historia US5 aceptada mientras los checks externos anteriores permanezcan pendientes.

La guardia de destino de carga se valida localmente con HTTPS, una etiqueta `staging` o `preview` y el rechazo de etiquetas productivas. El workflow invoca el mismo validador en Node.js antes de k6; no usa intérpretes ajenos al stack. Esta prueba no sustituye una ejecución real contra staging.

La implementación local no prueba la autenticación ni la consulta de métricas en Grafana Cloud. Para verificarlo, T059 debe configurar `GRAFANA_OTLP_METRICS_ENDPOINT` y `GRAFANA_OTLP_AUTHORIZATION`; después se necesita una ejecución real de `Delivery telemetry` y confirmar las series recibidas.

El manifiesto de fuentes infra/grafana/datasources.yaml y la guía de setup preparan la configuración declarativa sin URLs ni credenciales reales. La fuente GitHub, Prometheus de Grafana Cloud y SonarQube aún no están conectados ni probados; T059 sigue pendiente de cuenta/permisos y verificación remota.
